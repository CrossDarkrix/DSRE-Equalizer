# DSRE-Equalizer

**DSRE-Equalizer (Deep Sound Resolution Enhance Equalizer)** is an experimental Android application that captures audio currently being played on the device and applies lightweight real-time audio enhancement processing.

The current stable version is designed to subtly layer **Wet Delta** and **Air Assist** enhancement signals over the original playback audio.

---

## Overview

DSRE-Equalizer is a real-time audio processing application that captures audio being played on an Android device and applies lightweight compression, saturation, delta generation, and Air Assist processing to enhance clarity and perceived airiness.

Traditional pass-through approaches often result in the original playback audio overlapping with the reprocessed output, which can make echo-like doubling and latency artifacts more noticeable.

To reduce these effects, DSRE-Equalizer avoids simply layering a full-range processed signal on top of the original audio. Instead, it focuses on outputting only the difference generated by processing and subtle high-frequency enhancement components.

---

## Features

- Real-time capture of audio playback on Android
- Lightweight DSP processing based on MINI_DSRE
- Wet Delta mode
- Air Assist mode
- Adjustable input gain, assist gain, saturation amount, and other parameters
- Designed for operation in non-root environments
- Simple Material-style user interface
- Practical configuration with debug file logging minimized

## Processing Modes

### Mode 6: Full MINI_DSRE

Traditional MINI_DSRE processing:

```text
input
→ gain
→ compressor
→ saturation
→ output
```

The effect is easy to hear and understand, but because it overlaps with the original playback audio, audible doubling may occur depending on the environment.

### Mode 7: Wet Delta

Outputs only the difference between the processed and unprocessed signal:

```text
dry = input * gain
processed = MINI_DSRE(dry)
wet = processed - dry
output = wet * assistGain
```

Instead of replaying the original signal, only the changes introduced by processing are added as an enhancement layer.

This mode can help reduce perceived audio doubling.

### Mode 8: Air Assist

```text
dry = input * gain
processed = MINI_DSRE(dry)
wet = processed - dry
air = high-pass-like component from wet
output = blended assist signal * assistGain
```

Compared with Wet Delta, this mode places greater emphasis on high-frequency enhancement while reducing the perception of delayed low- and mid-frequency content.

## Recommended Initial Settings

```text
Mode: 8
Input Gain: 0.30
Threshold: 0.14
Ratio: 2.20
Makeup: 1.05
Saturation Drive: 1.22
Saturation Mix: 0.16
Output Gain: 1.00
Assist Gain: 0.20 - 0.35
Air Mix: 0.80
Air HP Alpha: 0.08
```

If the doubling effect feels too strong, first lower:

```text
Assist Gain: 0.15 - 0.25
```

If the effect is too subtle, gradually increase:

```text
Assist Gain: 0.30 - 0.40
```

## Current Behavior and Limitations

DSRE-Equalizer operates within the standard limitations imposed by Android.

As a result, it does not directly replace the audio output of other applications. Instead, captured audio is processed by DSRE and played back as an auxiliary enhancement signal.

Depending on the device and environment, the following behaviors may occur:

- The original audio and enhancement audio may overlap
- Slight latency may be noticeable in the processed output
- Capturable audio may vary depending on the target application or device
- Perceived effectiveness may vary significantly with volume settings

## Notes

This application is an experimental real-time audio processing tool.

Behavior may vary depending on the device, Android version, playback application, and audio output path.
